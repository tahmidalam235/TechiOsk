# TechiOsk - MERN E-commerce Project

This project is a full-stack e-commerce application built using the MERN stack (MongoDB, Express, React, Node.js).

## Features
- User authentication
- Product listing
- Shopping cart
- Order system

## Tech Stack
- Frontend: React
- Backend: Node.js + Express
- Database: MongoDB

## Run Locally

Frontend:
http://localhost:3000

Backend:
http://localhost:4000
